# Video Streaming Website

A modern **responsive video streaming web application** built with Flutter, designed to provide a clean and engaging browsing experience across different screen sizes.

## Overview

This project focuses on building a responsive web interface with a structured layout, reusable components, and an adaptive design approach.

It was developed as a practical project to strengthen my Flutter skills, particularly in **responsive UI development and web layouts**.

## Key Features

* Fully responsive web interface
* Adaptive layouts for different screen sizes
* Clean and modern UI
* Reusable Flutter widgets
* Structured and maintainable code
* Video streaming platform inspired interface

## Technologies

* **Flutter**
* **Dart**
* **Responsive & Adaptive UI**
* **Flutter Web**

## Purpose

This project is part of my continuous learning journey in Flutter development, with a focus on building real-world interfaces and improving my approach to responsive and adaptive design.
